# Заголовок — главная работа

В нарезках такого формата **нет субтитров-пересказа речи**. Есть один
статичный заголовок в одну-две строки, который висит весь клип.

Проверено покадрово по чужим удачным роликам: во всём клипе текст один
и тот же, без караоке-подсветки и смены фраз.

**Отсюда вывод:** механика (кроп, стек, рендер) — пять секунд работы скрипта.
Заголовок — это и есть продукт. Он продаёт клип в ленте.

---

## Три правила

### 1. Называть участников и ситуацию, но НЕ исход

Зритель должен захотеть узнать, чем кончилось.

| плохо | почему |
|---|---|
| «словил хедшот и не понял откуда» | итог назван, смотреть нечего |
| «опять сдох из-за своей жадности» | то же |

| хорошо | почему |
|---|---|
| «якут не признается что / дарят на др в Якутии» | есть кто и что, нет чем кончилось |
| «баба за рулем сбила / начальника» | завязка целиком, развязки нет |

### 2. Языком аудитории, а не литературно

Стилистика слов решает. Не «туалет», а «параша».

| вместо | писать |
|---|---|
| туалет, плохое место | параша |
| проиграл, слил игру | слил, потёк |
| выиграл в одиночку | затащил, вынес |
| матч, раунд | катка |
| союзник | тиммейт, тимка |
| старается | потный, потеет |
| злится | бомбит, горит |
| вышел из игры | ливнул |
| странный, нелепый | всратый, кринж |
| хорошо играет | выносит |
| убил выстрелом в голову | снял, стукнул |

Таблица — от конкретного канала. Под своего стримера её надо переписать:
слушать, какими словами говорит он сам и его чат.

### 3. Приём «пышное название на обыденность»

«УЖИН МИЛЛИАРДЕРА» — а в кадре макароны с колбасой.
Контраст между заголовком и картинкой работает лучше прямого описания.
Повторять.

## Форма

- **Две строки** — первая длиннее второй. Так в большинстве удачных чужих
  нарезок: первая ~83 % ширины кадра, вторая ~53 %.
- **До 22 знаков в строке** для однострочных стилей. Длиннее — движок мельчит
  кегль, и в ленте не читается.
- Цвет выбирается **автоматически по яркости фона**: жёлтый тонет на песке
  и небе, красный сливается на тёмном. Переопределить: `--caps` (красный
  капсом) или `--lower` (жёлтый строчными).
- Размер: высота заглавных ~2.9 % от высоты кадра, строка ~65 % ширины.
  Подбиралось в три захода: 1.46 % — мелко, 3.39 % — упирается в края.

## Мат

Мат в заголовке допустим, если это стиль канала. Но:

- **в экранном тексте он закрывается звёздочками автоматически** («бл**ь»),
  звук не трогается. Выключить — `--nocensor`;
- **мат в адрес конкретного непубличного человека** режет охват —
  такой момент лучше не брать вовсе;
- **оскорбления внешности** — уровень удаления ролика, без исключений
  для публичных людей.

## Описание под клип

Площадке нужен текст под видео. Рабочий шаблон:

```
Запись стрима ДД.ММ.ГГГГ <площадка>: <НИК> | <короткий заголовок> #тег1 #тег2 #тег3
```

- **дата — та, когда прошёл СТРИМ**, а не когда нарезали;
- заголовок в описании короткий, 3–6 слов, и **не обязан совпадать
  с надписью на видео**;
- хэштеги держать постоянным набором. На одном канале смена набора
  дала разницу 628 против 4 215 просмотров — набор менять без причины
  не стоит.

Выдавать описание вместе с каждым клипом, не дожидаясь просьбы.
