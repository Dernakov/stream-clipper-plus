# Как искать игровые моменты в записи стрима

> **Не используется с 2026-11-10.** Из записи стрима нарезаются только мемы,
> файты приходят готовыми клипами: `11-сырые-клипы.md`. Файл оставлен на случай,
> если решение изменится.

Бытовые моменты ищутся чтением расшифровки. Игровые ищутся связкой сигналов,
потому что момент происходит на экране, а не в речи. Инструмент даёт кандидатов;
решение принимается только после просмотра кадров.

## Порядок

1. `clipper.py scan`, `clipper.py asr` и `раскладка.py` по обычному порядку.
2. Поиск кандидатов:

   ```
   python движок/игра.py "<стрим>" --топ 15 --кадры
   ```

   Результат: таблица в консоли, `движок/work/<стрим>/game_candidates.json`
   и контактные листы в `движок/work/<стрим>/игра_кадры/`.
3. Посмотреть контактный лист каждого кандидата. Отбирать по правилам ниже.
4. Уточнить границы по пословным таймкодам, см. `01-порядок-работы.md`, правило 4.
5. Собрать стилем `wide`, посмотреть готовый файл кадрами.

## Сигналы

| Сигнал | Откуда | Что значит |
|---|---|---|
| Кодовая фраза | расшифровка | стример сам пометил момент, балл всегда максимальный |
| Слова | расшифровка | «на клип», «маркер», «затащил», «снял» и похожие |
| Голос | громкость звука | всплеск относительно обычной громкости стримера |
| Счёт | цифры вверху экрана Dota 2 | смена счёта, то есть убийство любой из команд |
| Движение | игровая часть кадра | бой, а не фарм или меню |

Таймер матча отсекает меню и разговорную сцену: вне идущей игры счёт не считается.

## Кодовая фраза

Если у стримера есть кодовая фраза, которую он говорит сразу после момента
(например «клипни это!»), её регулярное выражение задаётся в `CODE_PHRASE`
в `мои_настройки.py`. По умолчанию фразы нет.
Кандидат строится как 2 минуты до фразы. Это окно для просмотра, а не длина
ролика: итоговые границы выбираются по кадрам. Сама фраза в клип не входит:
конец куска надо поставить перед ней. 

## Что брать

- Бой с понятным исходом: убийство нескольких героев, спасение, камбэк.
- Реакция стримера совпадает с действием на экране.
- Понятно без знания матча: видно, кто на кого напал и чем кончилось.

## Что отбрасывать

- Счёт вырос, но стримера в бою нет: убийства на другом конце карты.
- Нет развязки или она случается после конца кадра.
- Интерфейс, инвентарь или поиск игры занимают большую часть момента.
- Оскорбления конкретного игрока, особенно по национальности или здоровью.

Сигнал «1 против 5» автоматически не определяется. Его можно подтвердить
только по кадрам: сколько врагов рядом и сколько союзников в бою.

## Сборка

```
python clipper.py cut "<стрим>" --start <сек> --dur <сек> --style wide ^
  --noshift --notighten --title "<заголовок>" --out "<имя>"
```

`--notighten` нужен, потому что бой идёт и в паузах речи. Длина 15–30 секунд:
без завязки игровой момент не читается.

Бой обычно шире куска игры, поэтому кадр ведётся за действием флагом
`--gametrack "СЕК:X,СЕК:X,..."`: секунда стрима и центр кадра в пикселях
исходника. Точки ставить по покадровому просмотру, примерно через 2 секунды.

Если бой стоит на месте, можно задать кусок игры флагом `--gamecrop Ш:В:X:Y`.
Пропорция 1080:1380, то есть ширина равна 0,7826 высоты. Лучше сдвинуть кадр,
чем уменьшать его: мелкая игра в вертикальном видео не читается.

## Другие игры

Считывание счёта настроено только для Dota 2. Положение цифр задано в начале
`движок/игра.py`. Для Counter-Strike этот сигнал надо настраивать отдельно по
кадрам реальной записи: лента убийств, счёт раундов, число живых игроков. Пока
он не настроен, на CS работают только слова, голос и движение.
