# Геометрия стрима: где вебка и откуда резать

Самое частое место, где всё ломается тихо. Числа чужого стрима на твоём
дадут полосу игры под лицом или кусок стены вместо человека — и заметно
это только глазами, на готовом файле.

## Главное: геометрия МЕНЯЕТСЯ

Не только у разных стримеров — **у одного и того же от записи к записи**.
Замеры одного канала:

| дата записи | окно вебки |
|---|---|
| запись 1 | 517×291 в точке (0, 490) |
| запись 2 | 471×265 в той же точке |
| запись 3 | 537×302 |
| запись 4 (другая площадка) | 533×300 |

Верхняя граница совпадала, правая и нижняя — нет: стример просто менял
размер окна в OBS. Старый кроп на новой записи тащил в кадр полосу пустыни
справа и снизу.

**Вывод: мерить каждую партию.** Это 30 секунд работы.

## Как мерить

```
python раскладка.py "СТРИМЫ/стрим.mp4"
```

Скрипт:

1. снимает 9 кадров по всему стриму;
2. усредняет их — движущееся смазывается, неподвижная рамка вебки остаётся
   резкой;
3. перебирает прямоугольники и требует, чтобы поддержаны были **все четыре**
   грани, а внутри картинка жила (это отсекает статичные таблицы и миникарты);
4. находит лицо внутри окна: движение, умноженное на признак кожи;
5. считает кропы под все пять стилей и кроп куска игры;
6. рисует картинки для проверки и печатает готовый блок настроек.

## Замер БЕЗ проверки глазами не принимать

Скрипт кладёт в `движок/work/<стрим>/раскладка/`:

| файл | что смотреть |
|---|---|
| `рамки.png` | зелёная рамка — окно вебки, цветные — кропы. Рамка должна сидеть ровно по краю окна |
| `кропы.png` | как будет выглядеть лицо в каждом стиле. Лицо целиком, не срезано |
| `контакт.png` | 9 кадров по всему стриму: не меняется ли раскладка по ходу |
| `сетка.png` | кадр с координатной сеткой — если считать границы руками |

Автоматика ошибается. Ранние версии этого скрипта уезжали то в панель
интерфейса, то в песчаную стену: песок по цвету ровно кожа, а камера
панорамирует, так что «кожа и движение» совпадало идеально.

**Если рамка села не туда** — снять границы по `сетка.png` и задать руками:

```
python раскладка.py "стрим.mp4" --окно X Y Ш В
```

Подсказки: `--угол право-низ` (где искать), `--без-вебки` (вебки нет вовсе).

## Что ещё задать руками

```
--верх N   отрезать сверху у кадра игры  (вотермарк стримера)
--низ N    отрезать снизу                (баннеры донат-алертов)
--лево N   запас между окном вебки и краем кадра игры
```

Эти два запаса — не косметика. Чужая графика в кадре режет охват молча,
см. `06-охват-и-риски.md`. Скрипт подсказывает, где нашёл постоянную
графику, но решать глазами.

## Два правила, которые нарушать нельзя

**1. Пропорция кропа обязана совпадать с блоком на холсте.**
Иначе картинку растянет. Скрипт это соблюдает сам; если правишь руками —
проверяй: `ширина кропа / высота кропа` должно равняться
`ширина блока / высота блока`.

**2. Держи запас 2–3 пикселя от края окна.**
Иначе в кадр попадёт линия рамки или полоска игры под ней.

## Куда класть результат

В `движок/мои_настройки.py`. Этот файл не перезаписывается при обновлении
шаблона. Скрипт печатает готовый блок — его надо просто вставить.

## Отдельные случаи

**Вебка на весь экран.** Стример разворачивает её, чтобы показать еду.
Обычный кроп в этот момент берёт кусок стены. Ловится только кадрами.
Лечится ручным `--camcrop Ш:В:X:Y` с пропорцией под нужный стиль.

**Текстовые донат-алерты по центру экрана.** Попадают в кроп игры целиком.
Это собственная графика стримера, но кадр всё равно смотреть обязательно.

**Стрим без вебки.** `--без-вебки`: посчитается только кроп игры.
Стили с лицом при этом недоступны.
