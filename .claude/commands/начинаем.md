# Начинаем

Эта команда — единственное, что пользователю надо помнить.
Она сама разбирается, первый это запуск или продолжение.

Пользователю нужен **только готовый ролик**. Запускай всё сам, не объясняй
процесс и не показывай вывод скриптов. Об ошибке пиши только если нужно его
решение: одной фразой, без технических подробностей.

---

## Шаг 1. Понять, первый ли это запуск

Есть ли файл `движок/мои_настройки.py`?

- **нет** → первый запуск, иди в раздел «Первый запуск»;
- **есть** → иди в раздел «Обычный запуск».

---

## Шаг 2. Проверить окружение (всегда)

```
python движок/проверка.py
```

Читай последнюю строку, она начинается с `ИТОГ:`.

**Если чего-то не хватает** — не вываливай вывод на пользователя. Скажи
простыми словами, чего нет и зачем оно нужно, и спроси разрешения поставить.
Команды установки скрипт печатает сам.

Порядок установки, если не хватает нескольких:
1. `ffmpeg` — без него не работает вообще ничего (в PATH или папка
   в переменной окружения `FFMPEG_DIR`);
2. пакеты Python в окружение проекта:
   `python -m pip install -r requirements.txt` в окружение проекта `.venv`;
3. модель распознавания скачается сама при первом разборе стрима (~1.5 ГБ,
   один раз, в `.cache/` проекта) — об этом стоит предупредить заранее,
   чтобы долгая первая загрузка не выглядела зависанием.

# Первый запуск

## Шаг 3. Прочитать базу знаний

Прочитай целиком, это быстро:

- `CLAUDE.md`
- `.claude/знания/01-порядок-работы.md` — свод правил
- `.claude/знания/02-что-искать.md`
- `.claude/знания/05-стили.md`

Остальные файлы `.claude/знания/` — по мере надобности, они перечислены
в `CLAUDE.md`.

## Шаг 4. Поздороваться и объяснить в трёх строках

Коротко: что этот проект делает, что нужно от пользователя (ссылка на стрим
или файл) и что будет на выходе. Без длинных вступлений.

## Шаг 5. Настройка — задать вопросы

Сначала спроси главное, одним вопросом:

> **Настроить под себя или взять всё как у автора шаблона?**
> - «Как у автора» — сразу в работу, все настройки проверены на практике.
>   Геометрию под конкретный стрим всё равно замерим отдельно.
> - «Пройду настройку» — 6 коротких вопросов про стримера, длину клипов,
>   шрифт и то, какие моменты искать.

Если выбрал «как у автора» — сразу шаг 6, вопросы не задавать.

Если выбрал настройку — спрашивай по два-три вопроса за раз, вариантами
на выбор, а не открытым текстом. Что выяснить:

1. **Чей стрим режем** — ник или название канала, и на какой площадке.
   Нужно для описаний под клипами и для понимания контекста.
2. **Откуда брать стримы** — Twitch / Kick / YouTube / файлом с диска.
3. **Куда заливать** — TikTok / Reels / Shorts (можно несколько).
4. **Длина клипов** — 8–20 сек (как у автора, по статистике выигрывает) /
   15–30 / 30–60 / по ситуации.
5. **Шрифт заголовков** — Montserrat ExtraBold (в комплекте) или свой.
   Если свой: попроси положить `.ttf` в `движок/fonts/` и назвать
   внутреннее имя шрифта, а не имя файла.
6. **Что искать в стриме** — быт и разговоры / игровые хайлайты / эмоции
   и крики / всё подряд. Можно несколько. Объясни в одну строку: по замерам
   бытовое даёт в разы больше просмотров, чем игра.
7. **Цензура мата в экранном тексте** — включена (как у автора) / выключена.

Не спрашивай про геометрию вебки, кропы, кегли и цвета. Это не пользовательские
решения — это замер, и его делает `/раскладка`.

## Шаг 6. Записать настройки

**Создай `движок/мои_настройки.py`.** Возьми за основу
`движок/мои_настройки.пример.py`. Пиши туда ТОЛЬКО то, что реально отличается
от умолчаний. Если пользователь выбрал «как у автора» — файл всё равно создай,
с шапкой-комментарием и без переопределений: его наличие означает
«настройка пройдена».

**Заведи память проекта.** Скопируй `.claude/память/ПАМЯТЬ.пример.md`
в `.claude/память/ПАМЯТЬ.md` — дальше работаешь с копией. Сам пример
не трогай: он лежит в репозитории и нужен, чтобы обновление шаблона
не затирало чужую память.

**Создай `.claude/память/мои-предпочтения.md`** — словами, не кодом:
кого режем, на какой площадке, куда заливаем, какие моменты искать,
какая длина. Это ты будешь читать в начале каждой сессии.

Добавь на него строку в `.claude/память/ПАМЯТЬ.md`.

## Шаг 7. Сказать, что делать дальше

Одним абзацем, без списка команд:

> Готово. Кидай ссылку на стрим (Twitch, Kick, YouTube) или файл — дальше
> я всё сделаю сам: скачаю, разберу, найду моменты, соберу клипы и принесу
> готовые файлы с описаниями.

Если у пользователя уже есть файл или ссылка — не жди, начинай нужную команду:
стрим целиком — `/мем`, сырые клипы или клип Twitch — `/файт`, одна игра для
YouTube — `/матч`.

# Обычный запуск

## Шаг 3. Поднять контекст

Прочитай:

- `.claude/память/ПАМЯТЬ.md` и файлы, на которые он ссылается;
- `.claude/знания/01-порядок-работы.md`;
- дальше по надобности.

## Шаг 4. Спросить статистику по прошлой партии

Если в памяти есть журнал клипов и там записана незакрытая партия —
спроси, что показали те клипы: просмотры, процент досмотров, пометил ли
TikTok что-нибудь. Ответ запиши в `.claude/память/статистика.md`.

Это не вежливость: без обратной связи выбор моментов не улучшается.

## Шаг 5. Короткий отчёт и вопрос

```
Окружение: всё на месте
Настройки: <кого режем, куда льём>
Прошлая партия: <дата, сколько клипов>

Что делаем? Кидай ссылку на стрим или файл.
```

Если пользователь сразу дал стрим — не отчитывайся, просто запускай
`/мем` (одна игра для YouTube — `/матч`, сырые клипы — `/файт`).
