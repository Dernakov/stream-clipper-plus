# Файт

Пользователь загрузил новую партию сырых клипов в `СЫРЫЕ КЛИПЫ/` (повторы OBS
от стримера) или дал ссылку на клип Twitch. Задача — собрать из каждого
вертикальный ролик по шаблонам и выдать готовую папку. Команды запускай сам, процесс не объясняй, вывод
скриптов не показывай. Пути к `python` и `ffmpeg` — в разделе «Окружение»
файла `CLAUDE.md`. Скрипты запускать из папки `движок`.

## 0. Рядом могут работать другие чаты

В соседних чатах одновременно могут идти `/мем` и `/матч`. Чтобы не мешать:

- этап писать только в `.cache/этап-файт.txt` (не в общий `этап.txt`),
  в конце записать `Готово`;
- свои разовые файлы класть в `.cache/файт/`, а не в корень `.cache/`;
- брать только файлы из `СЫРЫЕ КЛИПЫ/`; `СТРИМЫ/` и `СЫРЫЕ МАТЧИ/` не трогать;
- в журнал и память только дописывать в конец, ничего не переписывать.

## 1. Поднять контекст

Прочитай обязательно:

- `.claude/знания/11-сырые-клипы.md` — **главный документ: шаблоны, правила, приёмка**
- `.claude/знания/05-стили.md` — раздел «Заголовок не закрывает лицо и игру»
- `.claude/знания/03-заголовки.md` — как писать заголовок
- `.claude/память/мои-предпочтения.md`
- `.claude/память/журнал-клипов.md` — какие партии ещё не приняты

## 2. Найти клипы

- **Ссылка на клип Twitch** → скачать в сырые клипы:
  `python скачать.py "<ссылка>" --папка "../СЫРЫЕ КЛИПЫ"`. Файл ляжет как
  `twitch-clip-<слаг>.mp4`. Если ссылка ведёт не на клип, а на запись
  стрима (`/videos/…`), не качать: спросить, это мемы (`/мем`) или матч (`/матч`).
  Лимит скорости и очередь закачек — `.claude/commands/скачать.md`.
- Все `.mp4` в корне `СЫРЫЕ КЛИПЫ/` и в `СЫРЫЕ КЛИПЫ/смотреть последние 50 секунд/`.
- **Список файлов зафиксировать в начале** и сразу дописать в конец
  `.claude/память/журнал-клипов.md` строкой «партия <имя папки>: в работе, файлы: …».
  Файлы, подброшенные позже, идут в следующую партию.
- Если файл уже есть в партии из журнала, которую ещё не приняли, спросить
  пользователя, резать ли его заново.
- Папка пустая — коротко сказать об этом и остановиться.
- Записать этап в `.cache/этап-файт.txt` (например `1/5 Разбор сырых клипов`)
  и обновлять его по ходу.

## 3. Разобрать каждый клип

- Отрезок для разбора: клип целиком, а для папки «смотреть последние 50 секунд»
  только последние 50 секунд, всё раньше игнорировать.
- Расшифровать речь отрезка (`clipper.clip_words`) и снять раскадровку
  (кадр каждые 2 секунды). **Посмотреть кадры глазами.**
- Решить по каждому: игра (Dota 2 или CS), тип (Файт — игровой момент,
  Мем — разговор без интересной игры), где начать и закончить (убрать
  беготню, магазин, меню, пустые хвосты) и заголовок. Тип определять
  своим взглядом по кадрам; **если сомневаешься — Файт** (решение
  пользователя 2026-11-20), при приёмке он скажет, если переделать под мем.
- Клипы не отбрасывать: стример отобрал их сам. Один клип — один ролик.
- Для каждого Файта решить, нужен ли хук в начале, и если да — отрезок 3–7 с.
  Правила в `11-сырые-клипы.md`, раздел «Второй шаблон файтов: хук в начале».

## 4. Замерить геометрию

Каждый клип мерить заново, числа с прошлых клипов не переносить вслепую.

- **Dota 2:** правый край инвентаря (`hud_right`), окно вебки целиком
  (`cam_full`), правый верхний угол дубля вебки (`cam_cover`). Если раскладка
  совпадает с образцом, взять готовый файл геометрии из `движок/пробы/`:
  `geo_c1.json` (1664×936), `geo_c2.json` (крупная вебка), `geo_d1920.json`
  (1920×1080). Иначе сделать новый по их образцу.
- **CS:** `движок/пробы/geo_cs_шаблон.json`. Если разрешение или раскладка
  не как в образце, остановиться и обсудить с пользователем:
  вертикальный кроп для другого разрешения ещё не написан.
- **Подбородок:** для каждого клипа замерить нижнюю точку подбородка на вебке
  по 5 кадрам отрезка (флаг `--chin`). Вебку не приближать и по вертикали
  не резать.

## 5. Собрать ролики

Папка партии — одна на всю партию, даже если в ней есть мемы. Имя взять
один раз в начале сборки:

```
python clipper.py batchname --kind Файт --name "сырые клипы"
```

Печатает имя вида `Файт 2026-11-20 14-30 сырые клипы`: это папка
`Clips Ready/<имя>`. Имя ролика: `<номер> <Файт|Мем> <название>.mp4`.
Временную папку для скриптов проб брать внутри `.cache/файт/`.

- **Файт Dota 2:**
  `python пробы/варианты_файта.py "<клип>" "<врем. папка>" --title "<заголовок>" --only 6 --patch 2 --geo пробы/<geo>.json --chin <y> [--trim A-B]`
- **Файт CS:**
  `python пробы/варианты_cs.py "<клип>" "<врем. папка>" --geo пробы/geo_cs_шаблон.json --title "<заголовок>" --trim A-B`
- После этих двух скриптов дописать заставку: `clipper.append_outro(<ролик>, движок/<OUTRO_FILE>)`.
- **Хук** (если решено ставить): после заставки
  `python хук.py "<готовый ролик>" --hook A-B`, A и B — секунды готового ролика.
  Запускать один раз на ролик.
- **Мем:** `python clipper.py cut "<клип>" --style talk --start A --dur D --title "<заголовок>" --caps --camcrop <вебка на всю высоту, по ширине под блок> --gamecrop <игра без вебки> --notighten --noshift --wordsubs --batch "<имя из batchname>"`.
  Заставку движок ставит сам. Готовый ролик перенести в папку партии.

Заголовок сам встаёт по низу вебки, строки плотные: это уже в настройках.

## 6. Проверить по кадрам

У каждого готового ролика снять 1–2 кадра и проверить:

- [ ] заголовок под подбородком, прижат к низу вебки, на игру не залезает;
- [ ] в Доте дубль вебки закрыт плашкой Follow, в CS вебки в кадре игры нет;
- [ ] табло сверху и HUD снизу видны целиком;
- [ ] в конце заставка (длина = отрезок + ~2,5 с);
- [ ] если есть хук: в начале пик с реакцией, затем перемотка ◀◀ и ролик с начала.

## 7. Записать и отчитаться

- Дописать в конец `.claude/память/журнал-клипов.md` итог партии: исходные
  файлы, отрезки, заголовки, статус «на приёмке» (старые строки не править). По каждому Файту: хук да/нет,
  почему, отрезок хука.
- В отчёте пользователю по каждому Файту одной фразой: поставлен ли хук и почему.
- В `.cache/этап-файт.txt` записать `Готово`.
- Пользователю: путь к папке и таблица — номер, ролик, длина, что взято
  из клипа. В конце блок «👉 ВАШ ХОД»: пересмотреть и прислать правки по
  номерам или «принято».
- После «принято» — архив и удаление сырых клипов через `движок/приёмка.py`,
  порядок в `11-сырые-клипы.md`.
