# Раскладка стрима

```
python движок/раскладка.py "СТРИМЫ/стрим.mp4"
```

Делать **перед каждой новой партией**. Окно вебки меняется от записи
к записи даже у одного стримера — он двигает его в OBS. Чужие числа дают
полосу игры под лицом или кусок стены вместо человека.

## Обязательно посмотреть глазами

Скрипт кладёт картинки в `движок/work/<стрим>/раскладка/`:

| файл | что проверяешь |
|---|---|
| `рамки.png` | зелёная рамка сидит ровно по краю окна вебки? |
| `кропы.png` | лицо целиком в каждом стиле, не срезано? |
| `контакт.png` | раскладка одинаковая по всему стриму? |
| `сетка.png` | кадр с координатами — если считать руками |

**Не принимай замер без просмотра.** Автоматика ошибается: ранние версии
уезжали то в панель интерфейса, то в песчаную стену — песок по цвету ровно
кожа, а камера панорамирует.

## Если промахнулся

Сними границы по `сетка.png` и задай руками:

```
python движок/раскладка.py "стрим.mp4" --окно X Y Ш В
```

Ещё флаги: `--угол право-низ`, `--без-вебки`,
`--верх N` / `--низ N` (отрезать вотермарк сверху и баннеры снизу).

## Принять результат

Скрипт печатает замер. Проверь `рамки.png` глазами и запусти ещё раз с флагом
`--принять`: замер ляжет в `движок/work/<запись>/layout.json` и будет действовать
только для этой записи. В `движок/мои_настройки.py` числа раскладки не вписывать:
его читают задачи в соседних чатах, и чужие кропы попали бы к ним.

Подробности и разбор случаев — `.claude/знания/08-геометрия.md`.
