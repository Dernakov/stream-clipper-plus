# Скачать стрим

```
python движок/скачать.py "<ссылка>" --папка "<папка>"
```

Папка обязательна — задачи идут в соседних чатах параллельно, и файл
не должен попасть к чужим:

| Что качаем | `--папка` | Дальше |
|---|---|---|
| стрим целиком (мемы) | `СТРИМЫ` | `/мем` |
| запись одной игры (матч) | `СЫРЫЕ МАТЧИ` | `/матч` |
| клип Twitch (файт) | `СЫРЫЕ КЛИПЫ` | `/файт` |

Имя файла содержит номер записи или клипа (`twitch-<номер>`,
`twitch-clip-<слаг>`, `youtube-<id>`). Уже скачанный файл повторно не качается.

**Скорость и очередь.** По умолчанию скорость не ограничена. Получив ссылку,
до старта одной строкой предложить пользователю задать лимит скорости на эту
сессию (например «15 Мбит/с»; по умолчанию без лимита) и не ждать ответа, если
он не нужен: качать без лимита, лимит применить, когда ответит. Лимит
передаётся флагом `--скорость`, его значение на одну закачку: Мбит/с ÷ 8 ≈ МБ/с,
то есть 15 Мбит/с → `--скорость 1.8M`. Несколько ссылок качать
**последовательно**: одну до конца, затем следующую, а не одновременно.

Пока идёт скачивание, раз в 3 минуты писать пользователю одной строкой, сколько
скачано и сколько примерно осталось времени. Цифры брать из последней строки
лога, для отсчёта запускать Monitor. После окончания отчёты прекратить.

## Если не сработало

Прочитай `.claude/знания/07-скачивание.md` — там разобраны известные поломки
и обходы. Коротко:

- **Kick** — ссылка из адресной строки содержит id нового формата, который
  ломает yt-dlp. Скрипт подменяет его сам через API канала. Посмотреть список
  трансляций: `python движок/скачать.py "https://kick.com/КАНАЛ" --список`.
- **Живой стрим** — скачается огрызок. Скрипт предупреждает; дождаться конца.
- **Любая ошибка экстрактора** — первым делом обновить `yt-dlp` в окружении проекта (см. «Окружение» в `CLAUDE.md`).
  Они ломаются и чинятся постоянно.
- **TikTok по ссылке на ролик** не качается вовсе. Попросить пользователя
  скачать вручную и положить файл в `СТРИМЫ/`.

## Проверить уже скачанный файл

```
python движок/скачать.py "СТРИМЫ/файл.mp4"
```

Покажет разрешение, длительность и вес. Если ffprobe ругается на
`moov atom not found` — файл ещё качается, надо подождать.

## Про место на диске

Час стрима в 1080p60 — примерно 4 ГБ. Перед скачиванием длинной записи
имеет смысл сказать пользователю, сколько это займёт.
