# Мем

Пользователь дал ссылку или файл стрима. Задача — выдать готовые мемы
с описаниями. Команды запускай сам, процесс пользователю не объясняй.
Пути к `python` и `ffmpeg` — в разделе «Окружение» файла `CLAUDE.md`.

Если пользователь сообщил, что загрузил файлы в `СЫРЫЕ КЛИПЫ/` или дал ссылку
на клип Twitch, работать по `/файт` (`.claude/commands/файт.md`). Если это
запись одной игры для YouTube — по `/матч` (`.claude/commands/матч.md`).

## 0. Рядом могут работать другие чаты

В соседних чатах одновременно могут идти `/файт` и `/матч`. Чтобы не мешать:

- этап писать только в `.cache/этап-мем.txt` (не в общий `этап.txt`),
  в конце записать `Готово`;
- свои разовые файлы класть в `.cache/мем/`, а не в корень `.cache/`;
- работать только со своей записью из `СТРИМЫ/`; чужие папки, кэши
  и файлы в `СЫРЫЕ КЛИПЫ/`, `СЫРЫЕ МАТЧИ/` не трогать;
- в журнал и память только дописывать в конец, ничего не переписывать.

## 1. Поднять контекст

Прочитай обязательно:

- `.claude/знания/01-порядок-работы.md` — **свод правил, это главное**
- `.claude/знания/02-что-искать.md` — что именно искать в стриме
- `.claude/память/мои-предпочтения.md` — чего хочет этот пользователь
- `движок/README.md` — команды и флаги

Дальше по надобности: `03-заголовки.md`, `05-стили.md`, `06-охват-и-риски.md`,
`.claude/память/журнал-клипов.md` (что уже нарезано, чтобы не повторяться).

## 2. Достать файл

Ссылка → `python скачать.py "<ссылка>" --папка "../СТРИМЫ"`. Подробности и обходы —
`.claude/знания/07-скачивание.md`.

**Скорость и очередь.** По умолчанию скорость не ограничена. Получив ссылку,
до старта одной строкой предложить пользователю задать лимит скорости на эту
сессию (например «15 Мбит/с»; по умолчанию без лимита) и не ждать ответа, если
он не нужен: качать без лимита, лимит применить, когда ответит. Лимит
передаётся флагом `--скорость`, его значение на одну закачку: Мбит/с ÷ 8 ≈ МБ/с,
то есть 15 Мбит/с → `--скорость 1.8M`. Несколько ссылок качать
**последовательно**: одну до конца, затем следующую, а не одновременно.

Файл уже есть → `python скачать.py "<путь>"` покажет, что это за файл.

**Пока идёт скачивание, раз в 3 минуты писать пользователю** одной строкой:
сколько скачано и сколько примерно осталось времени. Просьба пользователя,
работает без напоминаний. Цифры брать из последней строки лога скачивания,
для отсчёта запускать Monitor. Как только скачивание закончено, отчёты прекратить.

**Файл может ещё качаться.** Признак — `moov atom not found` и растущий
размер. Тогда жди в фоне: пока размер не перестанет расти И ffprobe
не прочитает файл.

**Стрим может лежать несколькими частями** по 90 минут — это один стрим,
разрезанный на куски. Гнать конвейер по каждому файлу.

## 3. Замерить раскладку

```
python раскладка.py "<стрим>"
```

**Обязательно перед первой партией с нового стрима** — окно вебки меняется
от записи к записи, см. `.claude/знания/08-геометрия.md`.

**Посмотри `рамки.png` и `кропы.png` глазами.** Если рамка села не туда —
задай окно руками через `--окно`. Принятый замер сохрани запуском с `--принять`:
он ляжет в `движок/work/<запись>/layout.json` и будет действовать только для
этой записи. **В `мои_настройки.py` числа раскладки не вписывать** — их читают
и параллельные задачи. Свои кропы мема (`MEME_CAM_CROP`, `MEME_FILL_AREA` и т. п.)
для этой записи — тоже в её `layout.json`.

## 4. Прогнать конвейер

```
python clipper.py scan "<стрим>"
python clipper.py asr  "<стрим>"
python clipper.py pick "<стрим>"
```

`asr` на длинном стриме идёт долго — запускай в фоне. Время зависит
не от длины файла, а от количества РЕЧИ: где играет молча, 90 минут
считаются за 3–4 минуты; где говорит без остановки, три часа — 26 минут.

## 5. Выбрать моменты — ПОРЯДОК ВАЖЕН

1. **Прочитать расшифровку целиком**, набрать кандидатов.
   Сначала прочесать бытовые маркеры (см. `02-что-искать.md`), потом
   добирать громкое из `candidates.json`. Именно в таком порядке: бытовое
   ценнее и находится хуже.
2. **Вытащить кадры и посмотреть глазами. ДО заголовков.**
   На этом шаге отваливается примерно треть кандидатов: по речи бой,
   а на экране инвентарь, карта и лечение.
3. Снять пословные таймкоды, границы резать по акустике
   (`движок/точность.py`: `начало()`, `конец()`).
4. Только теперь писать заголовки.

## 5а. Игровые моменты из стрима не искать

Из записи стрима нарезаются только мемы. Файты приходят готовыми клипами в папку
`СЫРЫЕ КЛИПЫ/`, порядок описан в `.claude/знания/11-сырые-клипы.md`.

## 6. Собрать

**Один раз перед первым роликом** взять имя папки партии и передавать его
в каждый `cut`:

```
python clipper.py batchname "<стрим>" --kind Мем
```

Печатает имя вида `Мем 2026-11-20 14-30 twitch-123 5ч 12м`.

Мемы по умолчанию собирать шаблоном `meme`: вебка сверху, снизу без звука бой
из этого же стрима. Сначала найти по кадрам зрелищный бой нужной длины,
потом передать его начало в `--fill`. Подробно в `.claude/знания/05-стили.md`.

```
python clipper.py cut "<стрим>" --start <сек> --dur <сек> ^
  --style meme --fill <сек начала боя> --title "<заголовок>" --out "<имя>" ^
  --batch "<имя папки из batchname>"
```

Другие стили (`game|life|cam|duo|talk|wide`) брать, только если мем
в шаблон не ложится.

На каждом ролике стоит плашка с иконкой Twitch и ником стримера: ник берётся из
`STREAMER_NICK` в `движок/мои_настройки.py`. Если стрим другого автора, обязательно
передать его ник: `--nick "<ник>"`.

Полезные флаги: `--segments A-B,C-D` (сборка из кусков), `--xfade 0.45`
(наплыв), `--camcrop Ш:В:X:Y` (вебка на весь экран), `--noshift`, `--zoom`,
`--nosubs`, `--nocensor`. Все описаны в `движок/README.md`.

## 7. Чеклист перед отдачей

- [ ] **контактный лист из готового клипа, 6–8 кадров** — посмотреть самому:
      лицо в каждом кадре, текст не вылез, субтитры совпадают с картинкой;
- [ ] `python clipper.py check "<клип>"` — чужая графика;
- [ ] длина в районе 8–20 секунд без заставки;
- [ ] в конце есть заставка с иконкой Twitch и ником, см. `.claude/знания/09-результат.md`;
- [ ] заголовок не выдаёт развязку;
- [ ] заголовок не выше подбородка стримера и не на кадре игры, см. `05-стили.md` (субтитры в файтах стоят на игре, это норма);
- [ ] файт собран по шаблону «вся высота игры + плашка Follow», см. `11-сырые-клипы.md`;
- [ ] описание под каждый клип готово;
- [ ] дописать строку в конец `.claude/память/журнал-клипов.md` (только дописать);
- [ ] записать `Готово` в `.cache/этап-мем.txt`.

## 8. В конце

Коротко: какие клипы получились, чем цепляет каждый, какой стоит выложить
первым. Плюс описания под них. Клипы передаются стримеру, никуда их не загружай.

**Не натягивать количество.** С одного стрима 5 клипов, с другого 1 —
это нормальный итог, так и сказать.

## 9. После приёмки

Сказать, что всё готово, и ждать, пока пользователь пересмотрит ролики. Когда он
явно скажет, что всё принято, создать архив и удалить запись стрима:
`.claude/знания/09-результат.md`, раздел «Приёмка». Раньше этого не делать.
