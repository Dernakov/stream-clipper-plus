# stream-clipper-plus

**Запись стрима → готовые ролики: вертикальные мемы и файты для TikTok /
Reels / Shorts и горизонтальный ролик с целым матчем для YouTube.
Работает через [Claude Code](https://docs.claude.com/en/docs/claude-code/overview):
даёшь ссылку на Twitch или файл, получаешь папку с роликами.**

Всё локально: `ffmpeg` и распознавание речи на процессоре. Ни GPU, ни платных
API-ключей, ни онлайн-сервисов монтажа. Нужен только сам Claude Code.

Проект вырос из шаблона [sasha543359/stream-clipper](https://github.com/sasha543359/stream-clipper)
(MIT). В этом форке добавлены шаблоны `/файт` и `/матч`, движок для параллельной
работы нескольких чатов, хук с перемоткой, замер раскладки под каждую запись,
строка состояния с этапами и приёмка партий.

---

## Для чего это

Стрим идёт часами, а смотрят в основном короткие ролики. Отсмотреть восемь
часов записи, найти пару смешных минут, вырезать, переложить в вертикаль,
подписать и выровнять звук — это вечер монтажа на каждый стрим.

Этот репозиторий превращает Claude Code в такого монтажёра:

- **Клипмейкеру или стримеру** — регулярно получать ролики со своих
  трансляций без ручного монтажа: дал ссылку, забрал готовое.
- **Для TikTok, Reels, Shorts** — вертикальные мемы из разговоров
  и файты из игровых моментов, с заголовком, субтитрами, плашкой с ником
  и заставкой.
- **Для YouTube** — целая игра одним роликом, из которого вырезано
  скучное: загрузки, паузы, фарм в тишине, пустые меню.

Ролики Claude выбирает не по формуле, а смотрит на кадры и читает
расшифровку речи: так находятся моменты, которые не видны ни по громкости,
ни по движению. Последнее слово за человеком: всё готовое можно
пересмотреть и принять.

## Быстрый старт

```
git clone https://github.com/Dernakov/stream-clipper-plus
cd stream-clipper-plus
claude
```

Дальше одно слово:

```
> начинаем
```

Claude проверит, что стоит на компьютере, и скажет, чего не хватает.
Он спросит, чей стрим режем и что важно, и создаст личные настройки.
После этого работа выглядит так:

```
> /мем https://www.twitch.tv/videos/123456789
> /файт                       (клипы уже лежат в «СЫРЫЕ КЛИПЫ»)
> /матч https://www.twitch.tv/videos/123456789
```

Через какое-то время в `Clips Ready/` появляется папка с готовыми роликами
и описаниями к ним.

## Три шаблона

| Команда | Что на входе | Что на выходе |
|---|---|---|
| `/мем` (`/mem`) | ссылка Twitch на стрим целиком (2–8 ч) или файл в `СТРИМЫ/` | вертикальные мемы 1080×1920: разговорные моменты, вебка сверху, внизу без звука идёт бой из того же стрима |
| `/файт` (`/fight`) | файлы 16:9 в `СЫРЫЕ КЛИПЫ/` или ссылка на клип Twitch | вертикальные файты 1080×1920: игра во всю высоту, вебка, субтитры, по желанию хук с перемоткой в начале |
| `/матч` (`/match`) | ссылка на запись одной игры или файл в `СЫРЫЕ МАТЧИ/` | горизонтальный ролик 16:9 для YouTube: игра целиком без скучного, таймкоды спорных мест |

Шаблоны можно вести **одновременно в трёх разных чатах** Claude Code: у каждого
процесса свои временные файлы, раскладка привязана к записи, у каждой задачи
своя папка результата.

Служебные команды:

| Команда | Что делает |
|---|---|
| `/начинаем` | точка входа: первый запуск — настройка, дальше — подъём контекста |
| `/скачать` | скачать запись по ссылке (Twitch, Kick, YouTube) |
| `/раскладка` | замерить, где на кадре окно вебки, и посчитать кропы |
| `/статус` | окружение, настройки, что резали в прошлый раз |
| `/запомнить` | записать факт в память проекта |

## Кто что делает

| | |
|---|---|
| **Скрипт** | скачивает, режет аудио, распознаёт речь, ищет кандидатов по громкости, речи и движению, монтирует, рендерит |
| **Claude** | читает расшифровку, **смотрит кадры**, выбирает моменты, решает, что вырезать, пишет заголовки |
| **Ты** | даёшь запись, смотришь готовое и говоришь «принято» |

Механика занимает секунды. Вся ценность в выборе момента и в заголовке,
а формула смысла не понимает: тихую бытовую сценку она не видит, зато
находит езду на машине и таблицы после матча.

## Как здесь настроен Claude

Проект — это не только код, но и набор инструкций, по которым Claude ведёт
работу. Всё лежит в репозитории, читается и правится руками.

- **`CLAUDE.md`** — правила проекта: разделение труда, правило «кадры важнее
  расшифровки», работа в параллельных чатах, окружение. Claude Code читает его
  в начале каждой сессии.
- **`.claude/commands/`** — слэш-команды. Каждая расписана по шагам: что
  прочитать, какие скрипты запустить, когда смотреть кадры, что показать
  пользователю. Команды запускает сам Claude, вывод скриптов пользователю
  не показывается: на выходе только готовые ролики и описания.
- **`.claude/знания/`** — база знаний из 12 документов: что искать в стриме,
  как писать заголовки, удержание, раскладки, геометрия, охват и риски,
  скачивание, правила файтов и матчей. Это замеры и решения, а не общие слова:
  почему ролик на 8 секунд досматривают в разы чаще, чем на 30, почему чужая
  графика в кадре тихо режет охват, где заголовок не должен закрывать лицо.
- **`.claude/память/`** — память между сессиями: предпочтения, журнал роликов,
  статистика. Пополняется командой `/запомнить`. Лежит в `.gitignore`:
  у каждого своя, в репозитории только пример.
- **`.claude/settings.json`** — строка состояния и разрешения на запуск скриптов
  движка без лишних подтверждений.
- **`.claude/statusline.py`** — строка состояния показывает этап каждой команды
  (`мем 2/5 Выбор моментов · матч 5/7 Чистовик`). Этапы пишутся
  в `.cache/этап-<команда>.txt`.

Принципы, заложенные в инструкции:

- **Кадры важнее расшифровки.** Ни транскрипт, ни формула не видят
  инвентарь, экран смерти и смену сцены. Перед решением Claude смотрит листы
  кадров.
- **Не натягивать количество.** С одного стрима может выйти пять клипов,
  с другого один, и это нормально.
- **Спорное не вырезать.** В `/матч` всё сомнительное остаётся в ролике, а к нему
  прилагаются таймкоды, где можно ещё ужать. Последнее слово за человеком.
- **Качество важнее скорости.** Рендер `slow`/`CRF 17`, громкость поднимается
  одним усилением без компрессии, на склейках микрофейд звука против щелчков.
- **Приёмка.** Исходники удаляются, а ролики архивируются только после явного
  «принято» (`движок/приёмка.py`).
- **Ничего не загружать.** Автозаливки нет и не будет: площадки за это
  наказывают аккаунт. Публикует человек руками.

## Что нужно поставить

- **Claude Code** — [инструкция](https://docs.claude.com/en/docs/claude-code/overview)
- **Python 3.13** в окружении проекта `.venv` (на 3.15 нет сборки `onnxruntime`)
- **ffmpeg** — в PATH или папка в переменной окружения `FFMPEG_DIR`
- пакеты: `python -m pip install -r requirements.txt` в это окружение

```
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt      (Windows)
.venv/bin/python -m pip install -r requirements.txt          (macOS/Linux)
```

Удобнее всего запускать `claude` из активированного окружения
(`.venv\Scripts\activate` или `source .venv/bin/activate`): тогда `python`
в командах указывает на него, а разрешения из `.claude/settings.json`
срабатывают без лишних подтверждений.

Помнить это не обязательно: `начинаем` проверит и подскажет. Модель
распознавания речи (~1,5 ГБ) скачается сама при первом разборе. Все кэши
и временные файлы складываются в `.cache/` внутри проекта.

## Под своего стримера

1. **Раскладка.** Где на кадре окно вебки, у каждого стримера своё, и оно
   меняется от записи к записи:
   ```
   python движок/раскладка.py "СТРИМЫ/стрим.mp4"
   ```
   Скрипт найдёт вебку и лицо, посчитает кропы под все стили и нарисует
   картинки для проверки глазами. В шаблонах `/мем`, `/файт` и `/матч` Claude
   делает это сам для каждой записи.
2. **Личные настройки** — `движок/мои_настройки.py` (создаётся из
   `мои_настройки.пример.py`, лежит в `.gitignore`): шрифт, ник для плашки,
   длина клипов.
3. **Свои заставки и звуки** кладутся в `движок/заставка/` (тоже в `.gitignore`)
   и прописываются в настройках:
   ```python
   STREAMER_NICK = "мой_ник"                 # плашка с иконкой Twitch и ником
   OUTRO_FILE = "заставка/заставка.mp4"      # 1080x1920, в конец мемов и файтов
   MATCH_OUTRO = "заставка/концовка.mp4"     # 16:9, в конец ролика /матч
   HOOK_SOUND = "заставка/перемотка.mp3"     # звук перемотки в хуке файта
   ```
   Ничего из этого не обязательно: без файлов ролики собираются без заставок.

## Структура

```
CLAUDE.md              правила проекта и точка входа для Claude
.claude/commands/      слэш-команды
.claude/знания/        база знаний
.claude/память/        память между сессиями (личная, в .gitignore)
движок/                код: clipper.py (мемы, файты), матч.py, хук.py,
                       раскладка.py, скачать.py, игра.py, приёмка.py
СТРИМЫ/                стримы целиком для /мем
СЫРЫЕ КЛИПЫ/           клипы 16:9 для /файт
СЫРЫЕ МАТЧИ/           записи одной игры для /матч
Clips Ready/           готовые ролики
```

## Честные ограничения

- Проверено на Windows. На macOS и Linux должно работать (Python и ffmpeg),
  но вживую не проверялось.
- Игровые шаблоны (`/файт`, `/матч`, сигналы игры в `игра.py`) настроены
  под Dota 2, для файтов есть вариант под Counter-Strike. Для другой игры
  пороги и кропы придётся перемерить.
- Распознавание речи настроено на русский язык и процессор.
- `yt-dlp` то ломается, то чинится. Первое лекарство при ошибке скачивания —
  `python -m pip install -U yt-dlp`.
- Числа в базе знаний собраны на одном канале. Под другого стримера часть
  из них надо перемерить; где именно, написано в документах.

## Чего здесь нет

- Автозаливки, накрутки, обхода модерации, скачивания чужих готовых нарезок.
- Видео-образцов и заставок конкретного стримера: в репозитории только код,
  инструкции и шрифты.
