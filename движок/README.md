# Движок

Техническая часть. Пользователю сюда заходить не нужно — всё запускает Claude.
Этот файл для того, кто хочет понять, как оно устроено, или починить.

Из записи стрима 1920×1080 собирает вертикальные клипы 1080×1920.
Локально, без GPU и без платных API. Рендер одного клипа — 5–10 секунд.

## Что где

```
движок/
  clipper.py            конвейер: поиск моментов, монтаж, рендер
  config.py             настройки по умолчанию — НЕ править
  мои_настройки.py      личные настройки, переживают обновление шаблона
  мои_настройки.пример.py   образец со всеми ручками и объяснениями
  проверка.py           что стоит, чего не хватает
  скачать.py            Twitch, Kick, YouTube
  раскладка.py          замер геометрии стрима
  точность.py           точные границы слов по акустике, поиск лица
  fonts/                шрифт заголовков
  work/<имя стрима>/    кэш: аудио, расшифровка, кандидаты, замеры
```

Результат уезжает в `Clips Ready/` рядом с движком — код и результат разделены.

## Установка

```
pip install -r ../requirements.txt
```

`ffmpeg` ставится отдельно (winget / brew / apt). Модель распознавания
(~1.5 ГБ) скачается сама при первом `asr`.

Проверить всё разом: `python проверка.py`.

## Порядок команд

```
python скачать.py "<ссылка>"        запись стрима -> СТРИМЫ/
python раскладка.py "<стрим>"       где вебка, какие кропы
python clipper.py scan "<стрим>"    громкость, кандидаты      ~2 мин
python clipper.py asr  "<стрим>"    расшифровка речи          3-26 мин
python clipper.py pick "<стрим>"    свести речь и движение    ~1 мин
python clipper.py cut  "<стрим>" ...собрать клип              5-10 сек
python clipper.py check "<клип>"    чужая графика в кадре
```

`asr` зависит не от длины файла, а от количества РЕЧИ: где играют молча,
90 минут считаются за 3–4 минуты.

## Флаги `cut`

| Флаг | Что делает |
|---|---|
| `--style game\|life\|cam\|duo\|talk\|wide\|meme` | раскладка кадра |
| `--start СЕК --dur СЕК` | откуда и сколько |
| `--title "текст"` | заголовок, висит весь клип |
| `--out "имя"` | имя папки и файлов |
| `--batch "имя"` | имя папки партии в `Clips Ready`: нужно для сырых клипов |
| `--segments A-B,C-D` | собрать клип из нескольких кусков стрима |
| `--xfade СЕК` | наплыв между кусками, рабочее значение `0.45` |
| `--camcrop Ш:В:X:Y` | откуда брать вебку, если она развёрнута на весь экран |
| `--fill СЕК` | стиль `meme`: с какой секунды брать бой для нижней половины, без звука |
| `--fillsrc "файл"` | стиль `meme`: бой из другого файла, по умолчанию тот же стрим |
| `--gamecrop Ш:В:X:Y` | кусок игры для `talk`, `wide` и `meme` (у `meme` — кусок кадра боя) |
| `--zoom СЕК:КРАТ` | наезд на игру, напр. `4.5:1.35` |
| `--nosubs` | без субтитров речи |
| `--wordsubs` | пословные субтитры в игровой раскладке |
| `--notighten` | не вырезать паузы |
| `--noshift` | не двигать вход на первый громкий звук |
| `--caps` / `--lower` | заголовок красным капсом / жёлтым строчными |
| `--nocensor` | не закрывать мат звёздочками в экранном тексте |
| `--blurbg` | размытый фон вместо чёрных полей |
| `--nooutro` | не добавлять заставку из `OUTRO_FILE` в конец ролика |
| `--words файл.json` | проверенные руками слова вместо распознавания клипа |

### Про `--segments`

Абсолютные секунды стрима, куски склеиваются по порядку. Отменяет
`--start/--dur`. Два применения: собрать историю из далёких кусков
и пересобрать клип из тех кусков, которые площадка не пометила.

### Про `--xfade`

Наплыв гасит первые 0.45 сек куска. Если кусок начать ровно на атаке
слова — слово пропадёт. Перед первым словом нужна тишина длиной с наплыв,
после последнего тоже.

### Про `--camcrop`

Когда стример разворачивает вебку на весь экран (показывает еду), обычный
кроп берёт кусок стены. Заметно только глазами. Пропорция кропа обязана
совпадать с блоком стиля на холсте, иначе картинку растянет.

## Как ищутся моменты

Три сигнала: **абсолютная громкость** окна, **плотность речи** по расшифровке
и **движение в кадре игры**. Финальный выбор всё равно за человеком —
формула не понимает смысла.

### Ошибки, которые уже поймали

**«Всплеск после тишины» не работает.** Между матчами стример молчит, поэтому
любой возврат звука выглядел всплеском — топ забивался лобби и таблицами.
Заменено на абсолютную громкость.

**Эмоция без картинки — мёртвый клип.** Он часто орёт, разбирая послематчевую
таблицу. Поэтому меряется движение: статичные экраны ниже 2.3, бой 15–50.

**Клип начинался с тишины.** Первая заливка открывалась секундой молчания
при среднем просмотре 5.37 сек. Теперь `tune_start()` двигает вход на звук.

**Остаётся неточным:** езда на машине проходит оба фильтра — мотор громкий,
камера движется. Поэтому кадры смотрят глазами перед нарезкой.

## Вырезание пустот

Режется только то, где ОДНОВРЕМЕННО молчит стример и стоит картинка.
Одного молчания мало: он может молча целиться — это напряжение, а не пустота.

Порог движения двухуровневый: короткую паузу спасает бой, длинную —
только явный экшн, потому что 4 секунды тишины убивают удержание при любой
картинке.

Первые и последние 2 секунды клипа защищены — там не режется ничего.
Без этого обрывалось первое слово.

## Кэш

У каждого стрима свой: `work/<имя файла>/`. Внутри штамп с размером
исходника. Если новый файл называется как разобранный раньше, заводится
отдельная папка и печатается предупреждение.

Раньше кэш был общий, и это была мина: новый стрим молча резался
по расшифровке предыдущего. Чистить вручную не надо; если места жалко —
удалить папки целиком, пересоздадутся.

## Настройка вида

Всё в `config.py`, но править надо **`мои_настройки.py`** — он в `.gitignore`
и переживает обновление шаблона. Образец с объяснениями:
`мои_настройки.пример.py`.

Цвет в ASS пишется задом наперёд: `&HAABBGGRR`.
Жёлтый `#F6C80C` = `&H000CC8F6`, красный `#E31C1E` = `&H001E1CE3`.

## Обход, который может понадобиться на Windows

Smart App Control блокирует неподписанные DLL. У пакета `av` (его тянет
`faster_whisper`) такая DLL есть, и импорт падает с
`Политика управления приложениями заблокировала этот файл`.

В `clipper.py` есть `stub_av()`: подсовывает пустую заглушку вместо `av`,
потому что `faster_whisper` тянет его только ради превращения файла
в массив сэмплов, а аудио у нас уже извлечено ffmpeg-ом. Если политику
однажды отключат, заглушка не поставится — ветка выключит себя сама.

**Smart App Control выключать нельзя** — это дверь в одну сторону: включить
обратно можно только переустановкой Windows. Если блокировки пойдут дальше,
правильный следующий шаг — WSL2, а не отключение защиты.
